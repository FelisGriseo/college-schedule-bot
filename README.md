# College Schedule Bot

Асинхронний Telegram-бот коледжу на Python 3.11+, `aiogram 3.x`, SQLite/SQLAlchemy 2.0 та `uv`.

## Можливості

- читає базовий розклад з Excel-файлу з аркушами курсів та блоками груп;
- дозволяє обрати курс і групу через inline-клавіатуру;
- показує розклад на сьогодні, завтра або тиждень;
- слухає пости каналу через Telethon від вашого Telegram-акаунта, без прав адміністратора;
- під час запуску додатково перевіряє історію каналу за `BACKFILL_DAYS` днів;
- накладає заміни на Excel-розклад і виділяє їх як `🔄 ЗАМІНА` або `❌ ... скасовано`;
- зберігає групу та налаштування автосповіщень у SQLite;
Після першого вибору група зберігається у SQLite. Наступний `/start` одразу відкриває меню з цією групою; для зміни використовуйте кнопку `⚙️ Змінити групу`.
- має окрему точку розширення для OCR/LLM у `services/replacement_parser.py`.

## Формат Excel

Файл, вказаний у `BASE_SCHEDULE_FILE`, покладіть у корінь проєкту. Підтримуються два формати:

- плоский аркуш `Parsed_Schedule` з колонками
	`course`, `group`, `day`, `pair_number`, `pair_time`, `subject`, `teacher`, `room`;
- новий коледжний формат: окремі аркуші курсів (`1 курс`, `2 курс`, `3 курс`, `4 курс`), групи блоками по три колонки, день у колонці A, номер пари у колонці B, час у колонці C.

У коледжному форматі верхній рядок викладача/аудиторії трактується як чисельник, нижній — як знаменник. Поточний тиждень вважається знаменником, а кожен наступний тиждень чергується за датою. Наприклад, якщо поточний тиждень знаменник, через 7 днів буде чисельник.

`day` може бути українською, російською або англійською назвою дня тижня.

## Налаштування

1. Встановіть Python 3.11+ та `uv`.
2. Створіть оточення і встановіть залежності:

```powershell
uv sync
```

3. Заповніть `.env`: `TELEGRAM_TOKEN`, `API_ID`, `API_HASH`, `CHANNEL_USERNAME`, `SESSION_NAME` і `BASE_SCHEDULE_FILE`.
4. Додайте Excel-файл у корінь проєкту.
5. Переконайтеся, що Telegram-акаунт, який авторизує Telethon, підписаний на канал.
6. Запустіть:

```powershell
uv run main.py
```

Під час першого запуску Telethon попросить номер телефону, код із Telegram і, за потреби, пароль двофакторної автентифікації. Після цього створиться локальний файл `SESSION_NAME.session`; його не можна публікувати.

Боту не обов'язково бути адміністратором каналу. Він потрібен лише для діалогу з користувачами. Для читання каналу використовується авторизований Telethon-клієнт.

`BACKFILL_DAYS=30` означає, що при кожному запуску бот перечитує останні 30 днів постів. Старі знайдені заміни зберігаються без повторної розсилки сповіщень. Для одноразового повного історичного імпорту встановіть більше значення, наприклад `BACKFILL_DAYS=365`.

або:

```powershell
uv run college-schedule-bot
```

## Формат поста із заміною

Поточний regex-парсер очікує ключі, які легко адаптувати в `services/replacement_parser.py`:

```text
Заміна
Дата: 21.09.2026
Група: ПІ-231
Пара: 2
Предмет: Бази даних
Викладач: Іваненко І.І.
Кабінет: 126
```

Для фото заміни реалізуйте `extract_text_from_media`: туди можна підключити Tesseract/EasyOCR або vision API OpenAI/Gemini. Після отримання тексту він проходить тим самим `parse_replacements`.

## Одноразове OCR останнього поста

Щоб отримати лише найновіший пост каналу без прав адміністратора, використовуйте
`latest_replacement.py`. Скрипт працює через авторизований User API Telethon, завантажує
фото з цього поста та друкує розпізнаний EasyOCR-текст у консоль:

```powershell
uv run python latest_replacement.py
```

Потрібні залежності: `telethon`, `easyocr` та `python-dotenv` (усі вже є в
`pyproject.toml`). У `.env` достатньо вказати `API_ID`, `API_HASH` і, за потреби,
`CHANNEL_USERNAME=replacements_xpk` та `SESSION_NAME=schedule_monitor`.
Під час першого запуску Telethon попросить номер телефону, код входу та пароль 2FA,
якщо він увімкнений. Файл сесії не публікуйте.

Скрипт навмисно перевіряє тільки один найновіший пост. Якщо він не містить фото,
старі публікації не завантажуються.

## Автосповіщення

Користувач може перемкнути автосповіщення кнопкою меню. Після розпізнаної заміни бот надсилає повідомлення всім користувачам цієї групи, у яких сповіщення увімкнені.

## Перевірка

```powershell
uv run python -m compileall .
uv run ruff check .
```
