# College Schedule Bot

Асинхронний Telegram-бот коледжу на Python 3.11+, `aiogram 3.x`, SQLite/SQLAlchemy 2.0 та `uv`.

## Можливості

- читає базовий розклад з `college_schedule_2026_2027.xlsx`, аркуш `Parsed_Schedule`;
- дозволяє обрати курс і групу через inline-клавіатуру;
- показує розклад на сьогодні, завтра або тиждень;
- слухає пости каналу через Telethon від вашого Telegram-акаунта, без прав адміністратора;
- накладає заміни на Excel-розклад і виділяє їх як `🔄 ЗАМІНА` або `❌ ... скасовано`;
- зберігає групу та налаштування автосповіщень у SQLite;
Після першого вибору група зберігається у SQLite. Наступний `/start` одразу відкриває меню з цією групою; для зміни використовуйте кнопку `⚙️ Змінити групу`.
- має окрему точку розширення для OCR/LLM у `services/replacement_parser.py`.

## Формат Excel

Файл `college_schedule_2026_2027.xlsx` покладіть у корінь проєкту. Аркуш має називатися `Parsed_Schedule` і містити колонки:

`course`, `group`, `day`, `pair_number`, `pair_time`, `subject`, `teacher`, `room`.

`day` може бути українською, російською або англійською назвою дня тижня.

## Налаштування

1. Встановіть Python 3.11+ та `uv`.
2. Створіть оточення і встановіть залежності:

```powershell
uv sync
```

3. Заповніть `.env`: `TELEGRAM_TOKEN`, `API_ID`, `API_HASH`, `CHANNEL_USERNAME` та `SESSION_NAME`.
4. Додайте Excel-файл у корінь проєкту.
5. Переконайтеся, що Telegram-акаунт, який авторизує Telethon, підписаний на канал.
6. Запустіть:

```powershell
uv run main.py
```

Під час першого запуску Telethon попросить номер телефону, код із Telegram і, за потреби, пароль двофакторної автентифікації. Після цього створиться локальний файл `SESSION_NAME.session`; його не можна публікувати.

Боту не обов'язково бути адміністратором каналу. Він потрібен лише для діалогу з користувачами. Для читання каналу використовується авторизований Telethon-клієнт.

або:

```powershell
uv run college-schedule-bot
```

## Формат поста із заміною

Поточний regex-парсер очікує ключі, які легко адаптувати в `services/replacement_parser.py`:

```text
Заміна
Дата: 21.09.2026
Група: ПІ-231
Пара: 2
Предмет: Бази даних
Викладач: Іваненко І.І.
Кабінет: 126
```

Для фото заміни реалізуйте `extract_text_from_media`: туди можна підключити Tesseract/EasyOCR або vision API OpenAI/Gemini. Після отримання тексту він проходить тим самим `parse_replacements`.

## Автосповіщення

Користувач може перемкнути автосповіщення кнопкою меню. Після розпізнаної заміни бот надсилає повідомлення всім користувачам цієї групи, у яких сповіщення увімкнені.

## Перевірка

uv run python -m compileall .
